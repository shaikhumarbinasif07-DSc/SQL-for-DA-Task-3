# SQL-for-DA-Task-3
This is the Task 3(SQL for DA) of my Data Analyst Internship with Elevate labs.

## Objective

Use SQL queries to extract, manipulate and analyze data from an e-commerce database to generate meaningful business insights.

## Tool

SQLite

## Dataset

An e-commerce database containing information about:

- Customers
- Products
- Orders
- Order Items

## SQL concepts demonstrated

1. `SELECT`
2. `WHERE`
3. `ORDER BY`
4. `GROUP BY`
5. Aggregate Functions: `SUM()`, `AVG()`, `COUNT()`
6. `INNER JOIN`
7. `LEFT JOIN`
8. Subqueries
9. Revenue Analysis and Average Revenue per User
10. SQL Views
11. Indexes and `EXPLAIN QUERY PLAN`

## Files

- `task3_sql_queries.sql` – Complete SQL query script
- `ecommerce.db` – SQLite database
- `screenshots/` – Output screenshots of the SQL queries
