# SQL-for-DA-Task-3
This is the Task 3(SQL for DA) of my Data Analyst Internship with Elevate labs.

## Objective

Create an interactive Power BI dashboard to analyze Superstore sales, profit, orders and regional performance.

## Tool

Power BI

## Dataset

Superstore sales dataset containing information about:

- Orders
- Customers
- Products
- Categories and Sub-Categories
- Sales and Profit
- Regions and Customer Segments
- Order Dates

## Power BI concepts demonstrated

1. KPI Cards
2. Line Chart – Monthly Sales Trend
3. Bar Chart – Sales by Category
4. Bar Chart – Sales by Region
5. Table Visual – Customer-wise Sales and Profit
6. Slicers – Customer Segment
7. Interactive Filtering
8. Data Visualization and Formatting
9. Sales and Profit Analysis
10. Dashboard Design and Layout

## Dashboard Insights

- Total Sales: 22.64K
- Total Profit: 17.50K
- Total Orders: 5,837
- Profit Margin: 12.6%
- Highest Performing Region: West
- Top Sales Category: Technology
